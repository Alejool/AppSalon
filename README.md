# Barber Shop - Sistema de Gestión de Barbería

## Descripción
Barber Shop es un sistema de gestión para barberías que permite administrar citas, servicios y demás aspectos esenciales de un negocio de barbería. Desarrollado con **PHP, JavaScript y MySQL**, este proyecto facilita la organización y optimización del tiempo tanto para los barberos como para los clientes.

## Características
✅ **Gestión de servicios:** Agregar, editar y eliminar servicios ofrecidos por la barbería.
✅ **Reserva de citas:** Permite a los clientes agendar citas según la disponibilidad.
✅ **Visualización de citas:** Los barberos pueden ver fácilmente las citas programadas.
✅ **Cancelación de citas:** Los clientes pueden cancelar o reprogramar sus citas si es necesario.
✅ **Gestión de clientes:** Registro y seguimiento de clientes recurrentes.
✅ **Interfaz amigable:** Diseño intuitivo y fácil de usar.

## Tecnologías Utilizadas
- **Backend:** PHP
- **Frontend:** JavaScript 
- **Base de datos:** MySQL
- **Estilos:** CSS y Bootstrap para una mejor presentación

## Instalación
### Requisitos
- Servidor local (XAMPP, WAMP o LAMP)
- PHP 7.4+
- MySQL

### Pasos para ejecutar el proyecto
1. **Clonar el repositorio:**  
   ```sh
   git clone https://github.com/tuusuario/barber-shop.git
   ```
2. **Importar la base de datos:**  
   - Crear la base de datos en MySQL.
   
3. **Configurar la conexión a la base de datos:**  
   Editar el archivo `config.php` con los datos de conexión a la base de datos:
   ```php
   define('DB_HOST', 'localhost');
   define('DB_USER', 'root');
   define('DB_PASS', '');
   define('DB_NAME', 'barbershop');
   ```
4. **Ejecutar el proyecto en el servidor local:**  
   - Mover la carpeta del proyecto a `htdocs` (para XAMPP) o la carpeta de tu servidor local.
   - Acceder en el navegador a:  
     `http://localhost/barber-shop/`
